# Kontribusi

Terima kasih sudah mau membantu. Cara singkatnya:

1. Fork repo ini dan buat branch baru (`git checkout -b fitur-baru`).
2. Ubah `arabic-transliteration.ahk`. Pastikan tetap jalan di AutoHotkey v2.
3. Uji manual: aktifkan mode Arab dan coba contoh di README, termasuk kombinasi
   hamzah dan harakat.
4. Perbarui README (tabel pemetaan) dan CHANGELOG bila ada perubahan perilaku.
5. Buka Pull Request dengan deskripsi singkat apa yang berubah dan kenapa.

## Melaporkan masalah

Sertakan versi Windows, versi AutoHotkey, aplikasi tempat masalah terjadi,
urutan tombol yang diketik, hasil yang diharapkan, dan hasil yang didapat.

## Gaya penulisan kode

- Komentar singkat dan jelas, boleh berbahasa Indonesia atau Inggris
- Pemetaan baru ditaruh di tabel `m`, dikelompokkan sesuai kategorinya
